# 📌 About the Project

**Student Data Organizer** is a Python console-based application developed to manage student records efficiently through a simple menu-driven interface.

This project focuses on implementing Python fundamentals including **Lists, Dictionaries, Tuples, Sets, Loops, Conditional Statements, and Input Validation** while performing CRUD (Create, Read, Update, Delete) operations.

It is an excellent beginner-friendly project for learning data structures and real-world programming logic.

---

# ✨ Features

✅ Add New Student Records

- Unique Student ID
- Student Name
- Date of Birth
- Age Validation
- Grade
- Multiple Subjects

---

✅ Display All Students

- Shows every stored student record in a clean format.

---

✅ Update Student Information

Update student details using Student ID.

- Name
- Age
- Grade
- Subjects

---

✅ Delete Student Record

Remove a student's record using their Student ID.

---

✅ Display Student Subjects

View all subjects assigned to each student.

---

✅ Input Validation

- Numeric Student ID
- Numeric Age
- Prevents invalid inputs
- User-friendly error messages

---

# 🧠 Data Structures Used

| Data Structure | Purpose |
|---------------|---------|
| List | Stores all student records |
| Dictionary | Stores each student's information |
| Tuple | Stores Student ID and Date of Birth |
| Set | Stores unique subjects |
